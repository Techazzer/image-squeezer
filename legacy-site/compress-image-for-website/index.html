How slow images hurt your Google rankings

Since May 2021, Google includes Core Web Vitals (CWV) as a direct ranking factor. The key metric for images is Largest Contentful Paint (LCP) — how long it takes for the main image on a page to load. Google's threshold: good = under 2.5 seconds, poor = over 4 seconds. A 2MB hero image on a mobile connection can take 6–10 seconds — automatic "poor" rating and a ranking penalty.

Every 100KB you remove from your images is roughly 0.2–0.4 seconds off LCP on a mobile connection. Compressing a 2MB banner to 200KB can move a "poor" LCP score to "good" — directly improving your search ranking without any other changes.

Frequently Asked Questions

Should I use JPEG or WebP for my website images?

WebP is 25–35% smaller than JPEG at the same quality and is now supported by all modern browsers (Chrome, Firefox, Safari, Edge). If your CMS supports WebP (WordPress 5.8+, Shopify, and most modern builders do), use WebP. If you need maximum compatibility with older browsers or email, use JPEG. This tool outputs both — just select your format before compressing.

Do I still need an image optimisation plugin if I use this tool?

This tool handles manual compression before upload. WordPress plugins like Imagify or Smush re-compress images that are already on your server. If you pre-compress properly with this tool, you need less aggressive plugin compression — which means better quality. Many developers pre-compress with a tool like this and use a plugin only for automated resize on upload (different srcset sizes for responsive images).

What's the maximum image size I can upload to WordPress?

WordPress's default max upload size is set by your hosting's php.ini — typically 2MB to 64MB. But the real question is what size you should upload: under 200KB for any image that appears on a page. Larger images are fine as downloads, but images that load on a webpage should be compressed first.
